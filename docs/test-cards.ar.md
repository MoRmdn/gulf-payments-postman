# البطاقات التجريبية

[English](test-cards.md) · **العربية**

هذه البطاقات تعمل في **وضع الاختبار** فقط، وكل بوابة تنشرها بنفسها. راجع دائماً الصفحة الرسمية لأحدث قائمة.

## Moyasar

استخدم أي اسم من كلمتين على الأقل، وأي تاريخ انتهاء في المستقبل، وأي رمز CVC من 3 أرقام (4 أرقام لبطاقات Amex). البطاقات غير الموجودة في قائمة Moyasar تفشل دائماً.

| النوع | رقم البطاقة | النتيجة |
|---|---|---|
| Visa | `4111 1111 1111 1111` | ناجحة |
| مدى | `4201 3201 1111 1010` | ناجحة |
| Mastercard | `5421 0801 0100 0000` | ناجحة |
| Amex | `3400 0000 0900 000` | ناجحة |
| Visa | `4123 1200 0109 0000` | فاشلة: رصيد غير كافٍ |
| مدى | `4201 3200 0031 1101` | فاشلة: رصيد غير كافٍ |
| Mastercard | `5457 2100 0100 0092` | فاشلة: رصيد غير كافٍ |
| مدى | `4201 3212 3441 1220` | فاشلة: مرفوضة |
| Visa | `4111 1157 8422 8433` | فاشلة: البنك رفض التحقق 3-D Secure |

**STC Pay**

| رقم الجوال | رمز التحقق | النتيجة |
|---|---|---|
| أي رقم يبدأ بـ `05` (مثل `0512345678`) | `123456` | ناجحة |
| نفس الرقم | `111111` | فاشلة: رصيد غير كافٍ |
| `0515555555` | (بدون رمز) | فاشلة: الرقم غير مسجل في STC Pay |

القائمة الكاملة: [بطاقات Moyasar التجريبية](https://docs.moyasar.com/guides/card-payments/test-cards).

## Tap Payments

في صفحة الدفع من Tap استخدم الرمز **`100`**. **تاريخ الانتهاء هو الذي يحدد النتيجة**:

| تاريخ الانتهاء | النتيجة |
|---|---|
| `01/39` | ناجحة |
| `05/22` | مرفوضة |
| `04/27` | بطاقة منتهية |
| `08/28` | انتهت المهلة |

| النوع | رقم البطاقة | 3-D Secure |
|---|---|---|
| Visa | `4508 7500 1574 1019` | نعم |
| Visa | `4012 0000 3333 0026` | لا |
| Mastercard | `5123 4500 0000 0008` | نعم |
| Mastercard | `5111 1111 1111 1118` | لا |
| مدى | `4464 0400 0000 0007` | نعم |
| مدى | `5588 4800 0000 0003` | لا |
| Amex | `3714 4963 5398 431` (الرمز `1000`) | لا |

كي-نت (الكويت): `8888 8800 0000 0001`، تاريخ الانتهاء `09/30`، الرقم السري `1234`.

القائمة الكاملة: [بطاقات Tap التجريبية](https://developers.tap.company/reference/testing-cards).

## HyperPay

أي تاريخ انتهاء في المستقبل وأي رمز CVV من 3 أرقام.

| النوع | رقم البطاقة | 3-D Secure |
|---|---|---|
| Visa | `4200 0000 0000 0000` | لا (مستخدمة في البداية السريعة) |
| Mastercard | `5454 5454 5454 5454` | لا (مستخدمة في مجلدات الحجز) |
| Visa | `4711 1000 0000 0000` | نعم |
| Mastercard | `5212 3456 7890 1234` | نعم |

بالنسبة لبطاقات **مدى** التجريبية، اسأل HyperPay أو راجع توثيقها، لأن مدى غالباً تحتاج entity id خاصاً بها.

القائمة الكاملة: [معاملات الاختبار في HyperPay](https://hyperpay.docs.oppwa.com/reference/parameters) و [دليل اختبار 3-D Secure](https://hyperpay.docs.oppwa.com/tutorials/threeDSecure/TestingGuide).
